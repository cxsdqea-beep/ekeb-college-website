## 📌 О проекте

Веб-портал колледжа разработан для абитуриентов, студентов и преподавателей. Сайт включает в себя интерактивную информацию об учебных специальностях, условиях поступления, дуальном обучении, студенческой жизни и блоге директора.

### Ключевые возможности

- 🎓 **Каталог специальностей**: Подробные карточки направлений подготовки с квалификациями, сроками и описанием учебного процесса.
- 📝 **Онлайн-подача заявки**: Интерактивная форма подачи заявления на поступление.
- 📋 **Пошаговый гид поступления**: Этапы поступления, список необходимых документов и требования.
- 🏛️ **Информационный хаб колледжа**: Администрация, структура, устав, лицензии и нормативная документация.
- ✍️ **Блог директора & Ящик доверия**: Прямая связь руководства колледжа со студентами и родителями.
- 📰 **Новости и студенческая жизнь**: Актуальные события, достижения, общежитие и мероприятия.
- 📱 **Полная адаптивность**: Оптимизация под любые экраны (смартфоны, планшеты, десктопы).

## 🚀 Быстрый старт

### Требования
- [Node.js](https://nodejs.org/) (версия 18 или выше)
- npm или yarn / bun / pnpm

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/cxsdqea-beep/ekeb-college-website.git
   cd ekeb-college-website
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте приложение в браузере по адресу: [http://localhost:3000](http://localhost:3000)

### Сборка для продакшена

```bash
npm run build
```
Собранные статические файлы будут находиться в папке `dist/`.
